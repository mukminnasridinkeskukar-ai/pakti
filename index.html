Cara Menggunakan PAKTI

1. Dashboard Data

Halaman utama menampilkan statistik pengajuan dalam bentuk kartu dan grafik. Klik kartu untuk melihat detail data pengajuan per status.

2. Formulir Pengajuan

Isi formulir dengan data lengkap. Upload 4 dokumen wajib: Foto 4x6, SK Pangkat, SK Jabfung, dan PAK Konvensional. Setelah submit, nomor register akan terbit otomatis dan dapat diunduh.

3. Pemantauan Proses

Pantau status pengajuan Anda. Admin dapat melihat detail dan mengubah status pengajuan.

4. Cek PAK Terbit

Cari data PAK yang sudah terbit menggunakan NIK/NIP. Dokumen dapat di-preview dan diunduh.

5. Cek Status Pengajuan

Masukkan NIP untuk melihat status terbaru pengajuan Anda. Jika status "Perbaikan", Anda dapat mengupdate data langsung.

Panduan Admin

Menu admin hanya dapat diakses oleh pengguna dengan role admin.

Data Master

Data master adalah sumber data utama untuk Pembuatan PAK Integrasi. Admin dapat menambah, edit, hapus data, atau upload massal via CSV.

Pembuatan PAK Integrasi

Pilih pegawai dari Data Master, lalu klik "Generate 4 Dokumen PAK" untuk membuat 4 dokumen (Konvensional, Integrasi, Kebutuhan AK, PAK Integrasi) dalam 1 PDF.

Editor Dokumen

Klik "Edit Dokumen" untuk mengedit dokumen seperti Microsoft Word. Perubahan tersimpan otomatis ke database.

Kelola Data Pengajuan

Admin dapat mengelola semua data pengajuan: edit, update status, hapus, export CSV, dan upload massal.

Pertanyaan Umum (FAQ)

Q: Bagaimana cara mengajukan PAK?

Buka menu "Formulir Pengajuan", isi data lengkap, upload 4 dokumen wajib, lalu klik "Submit Pengajuan". Nomor register akan terbit otomatis.

Q: Berapa lama proses verifikasi?

Proses verifikasi memakan waktu 3-5 hari kerja setelah dokumen lengkap diupload.

Q: Apa yang dilakukan jika status "Perbaikan"?

Buka menu "Cek Status Pengajuan", masukkan NIP, lalu klik "Update Data Perbaikan". Perbaiki data sesuai catatan admin.

Q: Bagaimana cara mendapatkan PAK yang sudah terbit?

Buka menu "Cek PAK Terbit", masukkan NIK/NIP. Jika status "Terbit", dokumen dapat di-preview dan diunduh.

Q: Dokumen apa saja yang perlu diupload?

  • Foto berwarna 4x6 cm (JPG/PNG, maks 2MB)
  • SK Pangkat Terakhir 2022/2023 (PDF, maks 1MB)
  • SK Jabatan Fungsional 2022/2023 (PDF, maks 1MB)
  • PAK Konvensional s/d 2022 (PDF, maks 1MB)
Jika masih ada pertanyaan, hubungi kontak PIC di halaman sebelumnya.

Panduan Administrator

Panduan khusus untuk administrator sistem PAKTI. Menu administrasi hanya dapat diakses oleh pengguna dengan role admin.

Menu Administrasi

Saat login sebagai admin, Anda memiliki akses ke menu administrasi berikut:

  • Panduan Admin — Buku panduan ini
  • Data Master — Kelola data master pegawai
  • Pembuatan PAK Integrasi — Generate 4 dokumen PAK
  • Kelola Data Pengajuan — CRUD data pengajuan publik

Login Admin

Untuk mengakses menu administrasi, login dengan kredensial yang telah diberikan. Hubungi Koordinator PAK jika Anda memerlukan akses admin.

Peran Admin

Administrator bertanggung jawab untuk:

  • Verifikasi dan validasi data pengajuan dari pemohon
  • Update status pengajuan (Menunggu → Perbaikan/Ditolak/Terbit)
  • Kelola data master untuk Pembuatan PAK Integrasi
  • Generate dan cetak dokumen PAK dalam format PDF
  • Edit dokumen PAK menggunakan editor Word-like
  • Upload massal data via CSV
  • Export data pengajuan ke CSV/Excel

Data Master (Sheet DATA)

Data Master adalah sumber data utama untuk Pembuatan PAK Integrasi. Berbeda dari data pengajuan publik.

Tambah Data Master

  1. Klik tombol "Tambah Data" di kanan atas
  2. Isi formulir lengkap (36 field): identitas pegawai, AK lama/baru, AK minimal, nilai dasar, pejabat penilai
  3. Klik "Simpan"

Upload Massal CSV

  1. Klik "Upload Massal CSV"
  2. Download template CSV (sudah berisi 3 contoh data valid)
  3. Edit template di Excel/Google Sheets
  4. Upload file CSV yang sudah diisi
  5. Preview akan muncul dengan validasi otomatis
  6. Klik "Upload ke Database"

Edit & Hapus Data

Setiap baris data memiliki tombol:

  • Edit — Edit semua field data master
  • Hapus — Hapus data (dengan konfirmasi)

Pembuatan PAK Integrasi

Generate 4 dokumen PAK dalam 1 file PDF dari data yang ada di Data Master.

Cara Generate Dokumen PAK

  1. Buka menu "Pembuatan PAK Integrasi"
  2. Pilih pegawai dari dropdown (data dari Data Master)
  3. Klik "Generate 4 Dokumen PAK"
  4. Preview 4 halaman akan muncul
  5. Klik "Print / Save as PDF" untuk download

4 Dokumen yang Dihasilkan

  • Halaman 1: Penetapan Angka Kredit Konvensional
  • Halaman 2: Penyesuaian AK ke Integrasi
  • Halaman 3: Perhitungan Kebutuhan Kekurangan AK
  • Halaman 4: Penetapan Angka Kredit Integrasi
Pastikan data di Data Master sudah lengkap sebelum generate dokumen PAK.

Editor Dokumen PAK

Editor mirip Microsoft Word untuk mengedit dokumen PAK secara langsung.

Membuka Editor

  1. Generate dokumen PAK seperti biasa
  2. Klik tombol "Edit Dokumen"
  3. Editor fullscreen terbuka dengan halaman A4

Fitur Editor

  • Menubar: File, Edit, View, Insert, Format, Table, Tools
  • Toolbar: Bold, Italic, Underline, Font, Size, Color, Alignment, List
  • Tabel: Insert, edit row/column, merge cell, properties
  • Image: Upload gambar dari komputer
  • Page Break: Pisah halaman dokumen
  • Ruler: Visualisasi margin & lebar halaman

Autosave

Perubahan disimpan otomatis ke database setiap 2 detik setelah berhenti mengetik. Status penyimpanan terlihat di header editor.

Version History

Klik tombol "Versi" untuk melihat riwayat perubahan. Setiap save membuat versi baru. Anda dapat memulihkan (restore) versi sebelumnya.

Kelola Data Pengajuan

Admin dapat mengelola semua data pengajuan dari pemohon: edit, update status, hapus, export, dan upload massal.

Update Status Pengajuan

  1. Klik tombol (Update Status) pada baris data
  2. Pilih status baru: Menunggu, Perbaikan, Ditolak, atau Terbit
  3. Tulis catatan admin (opsional)
  4. Klik "Simpan"

Edit Data Pengajuan

  1. Klik tombol (Edit) pada baris data
  2. Edit field yang perlu diperbaiki
  3. Upload ulang dokumen jika diperlukan (opsional)
  4. Klik "Simpan Perubahan"

Hapus Data

  1. Klik tombol (Hapus)
  2. Konfirmasi penghapusan

Upload Massal & Export

Upload Massal CSV (Pengajuan)

  1. Klik "Upload Massal CSV" di header Kelola Data Pengajuan
  2. Download template CSV
  3. Isi data (3 field wajib: email, nama, nip)
  4. Upload file → preview dengan validasi otomatis
  5. Klik "Upload ke Database"

Export Data

  1. Klik "Export CSV" di header
  2. File CSV terdownload dengan semua data pengajuan
  3. Buka di Excel/Google Sheets

Printout Data

Klik tombol "Printout" untuk mencetak halaman tabel data. Gunakan print dialog browser untuk Save as PDF.

Keamanan & Hak Akses

Menu administrasi hanya dapat diakses oleh pengguna dengan role admin.

Role Pengguna

  • Admin: Akses penuh ke semua menu administrasi
  • SDMK: Akses terbatas sesuai satuan kerja
  • Publik: Hanya bisa lihat Dashboard, Formulir, Tracking, Cek Status (tanpa login)

Tips Keamanan

  • Jangan bagikan kredensial admin
  • Logout setelah selesai menggunakan sistem
  • Periksa data sebelum update status
  • Gunakan editor dokumen dengan hati-hati

FAQ Admin

Q: Bagaimana cara menambah admin baru?

Hubungi developer/IT untuk menambahkan user admin baru melalui database Supabase (tabel admin_users).

Q: Data Master berbeda dengan Data Pengajuan?

Ya. Data Master adalah sumber untuk Pembuatan PAK Integrasi. Data Pengajuan adalah data yang disubmit oleh pemohon melalui Formulir Pengajuan.

Q: Apakah editor dokumen bisa undo/redo?

Ya. Gunakan Ctrl+Z (undo) dan Ctrl+Y (redo). Atau klik tombol undo/redo di toolbar.

Q: Apakah autosave benar-benar menyimpan ke database?

Ya. Autosave menyimpan ke tabel dokumen_pak di Supabase setiap 2 detik setelah berhenti mengetik.

Q: Bagaimana cara restore versi dokumen lama?

Klik tombol "Versi" di editor, pilih versi yang ingin dipulihkan, lalu klik "Pulihkan".

Q: Mengapa dokumen PAK harus 4 halaman?

4 dokumen (Konvensional, Integrasi, Kebutuhan AK, PAK Integrasi) wajib ada sesuai format standar. Setiap dokumen = 1 halaman A4.
